Led the mechanical design team on a faculty-advised senior capstone (Group A7, sponsored by GOW-MAC Instrument Co., advised by Dr. Zahra Pournorouz) building a programmable GC oven — the core challenge being not just fast heating, but fast cooldown between sample runs, since that's what actually limits GC throughput. Measured cooldown across three repeated trials confirmed the design: from roughly 400°C down under 50°C in about 20 minutes, and back to near-ambient by roughly half an hour.

Built an autonomous puck-sorting robot in MATLAB's Robotics Playground with a 5-person team (ME 598, Group WS8): the robot locates two RGB-colored pucks using a forward-facing color detector, delivers each to its matching colored zone, and returns to the arena's origin — tested across all six possible puck-color permutations. Navigation runs on a Stateflow state machine (search → grab → escort → return), with zone/origin guidance computed outside the state machine in Simulink to avoid algebraic loops. The standout piece is the wall-avoidance layer: instead of a heuristic repulsion behavior, it analytically derives the minimum safe clearance from the robot's own geometry — using an empirically measured 0.165m offset between the side sensor and the robot's actual collision boundary — then runs as a continuous corrective layer capped at 75% authority, so it steers the robot away from walls without overriding the state machine's intent unless a collision is geometrically unavoidable, at which point a full-authority "panic" maneuver takes over.

  • All 6 puck-color permutations succeeded (RG, RB, GR, GB, BR, BG)
  • Fastest run: red-green in 82.1s; average ~120s across all 6
  • Wall clearance derived analytically from sensor geometry, not tuned by hand
  • Wall-avoidance capped at 75% authority except in a full-override "panic" mode
  • Best run documented on video

Built an RRT planner over a 2D obstacle field, then propagated a linear Kalman filter along each planned path to predict the growth of localization uncertainty — the robot only gets a position fix when a range beam has line of sight to an obstacle edge, so uncertainty balloons in open space and shrinks near walls. Across 100 randomized RRT trials, path length turned out to barely predict final confidence: the shortest path found (length 102.0) ended among the least confident outcomes (uncertainty 148.1, close to the trial-wide max of 158.0), while a path only 10% longer (112.0) that stayed closer to obstacle edges ended over 20x more confident (uncertainty 7.0) — showing that what a robot can see along a route matters more than how far it travels.

  • 100 RRT trials, each propagated through a linear Kalman filter
  • Shortest path (102.0) landed near the worst-case uncertainty (148.1 of a 158.0 max)
  • Min-uncertainty path (112.0, only 10% longer) reached 7.0 — over 20x more confident
  • Uncertainty quantified as the trace of the terminal error covariance matrix P

Implemented and compared two discrete-time SLAM approaches — batch least squares and a linear Kalman filter — for a mobile robot navigating a hallway by odometry alone versus odometry fused with range measurements to three point-landmark doors, averaged over 1000 trials each. Odometry-only position error grew steadily to roughly 0.26m over a 100-second traversal for both estimators; adding landmark measurements suppressed batch least squares' drift only modestly (to ~0.21m), but nearly eliminated the Kalman filter's, dropping it to ~0.005m at first landmark contact and holding it near the sensor noise floor for the rest of the run.

  • Compared batch least squares vs. linear Kalman filter, 1000 trials each
  • Odometry-only drift reached ≈0.26m over a 100s traversal
  • Landmark fusion: least squares improved to ≈0.21m, Kalman filter to ≈0.005–0.02m
  • Back-and-forth run confirms loop closures re-constrain the outbound trajectory, not just post-contact
